# Proyecto-Ciencia-de-Datos-1
¿Es posible identificar a los estudiantes de grados 6.º a 11.º con mayor riesgo de deserción escolar mediante un modelo de clasificación supervisada que utilice variables de asistencia, nivel socioeconómico, acceso a internet, zona y desempeño académico? 

**Importante** : Este dataset es simulado, brindado por el docente de la materia.

**DATASET** :Educación — Desempeño académico Estudiantes de instituciones urbanas y rurales, grados 6° a 11° (sin ciudad puntual). Incluye asistencia, nivel socioeconómico, acceso a internet y puntajes.

**Integrante 1:** Joel Montenegro – Liderazgo de datos: revisión de calidad, limpieza, tratamiento de valores faltantes, análisis exploratorio y elaboración del diccionario de datos. 

**Integrante 2:** Kinan El halabi – Liderazgo analítico: selección de variables, construcción del modelo, validación, análisis de resultados y evaluación de sesgos. 

Responsabilidades compartidas: documentación, gestión del repositorio Git, redacción, reflexión ética y presentación del proyecto.
